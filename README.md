# Qlik ETP Directory

Prototype and WordPress-ready assets for a searchable Emergency Transition Program (ETP) organization directory.

## What's Included

- Standalone HTML prototypes for directory search, filtering, maps, and different result-loading patterns.
- Emergency help resource data in JSON format.
- Mockup screenshots for the WordPress admin experience.
- A `WPReady` folder with WordPress-oriented plugin, markup, CSS, JavaScript, and configuration files.

## Key Files

- `directory-qlik-prototype.html` - Main directory prototype.
- `directory-qlik-prototype-infinite.html` - Infinite-scroll version.
- `directory-qlik-prototype-load-more.html` - Load-more pagination version.
- `directory-qlik-prototype-qlik-paged.html` - Qlik paged version.
- `directory-qlik-prototype-emergency-help.html` - Version with emergency help resources.
- `directory-friendly-mock.html` - Simplified functional mockup.
- `wp-emergency-help-admin-mockup.html` - WordPress admin mockup.
- `emergency-help-resources.json` - Emergency help resource data.
- `WPReady/` - WordPress-ready implementation assets.
- `mockup-screenshots/` - Screenshots documenting admin UI states.

## Viewing the Prototypes

Open any of the HTML prototype files directly in a browser. No build step is required for the standalone mockups.

## WordPress Assets

The `WPReady` folder contains files intended to support a WordPress implementation, including:

- Plugin PHP files.
- Dashboard markup.
- Stylesheets.
- JavaScript module code.
- Emergency help resource data.

Review and test these files in a WordPress environment before deploying them to a live site.
